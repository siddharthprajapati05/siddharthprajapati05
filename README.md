## 👋 About Me

I'm an **AI/ML enthusiast and full-stack developer** who loves taking an idea all the way from a trained model to a working product.

- 🧠 I **train and fine-tune AI models**, including open-weight LLMs with LoRA / PEFT and 4-bit quantization
- 🤖 I **build AI-powered applications** such as RAG assistants, computer vision systems and generative AI tools
- 🌐 I **develop full-stack products** with React, Node.js, FastAPI and PostgreSQL, and deploy them on Linux, Docker and the cloud
- 📊 I care about **measuring results**, so I build evaluation pipelines that compare baseline vs improved models
- 🕵️ Fun fact: I enjoy debugging more than coding. It feels like solving a mystery.
